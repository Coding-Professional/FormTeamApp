# FormTeamApp

**FormTeamApp** is a responsive web application made with "ANGULAR JS" designed to streamline team formation processes. Built with modern web technologies, it offers an intuitive interface for users to create, manage, and participate in team-based activities efficiently.
This repo is created to complete the task assigned by the Heliverse Pvt ltd.

## Features

- User-friendly   
- Responsive design for mobile and desktop  
- Simple and clean UI/UX  
- Easily customizable for different team structures

## Tech Stack

- **Frontend**: HTML, CSS, Angular Js  
- **Version Control**: Git & GitHub

## 🧑‍💻 Getting Started

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Coding-Professional/FormTeamApp.git

2. Navigate to the project directory:

   ```bash
   cd FormTeamApp

3. Open index.html in your browser.
